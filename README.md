# PDF Manager - UAS PBO

Aplikasi manajemen file PDF berbasis web.

## Fitur
- Upload PDF
- Lihat PDF
- Download PDF
- Rename PDF
- Hapus PDF
- Pencarian file

## Cara Menjalankan
1. Install Node.js
2. Jalankan `npm install`
3. Jalankan `node server.js`
4. Buka browser ke `http://localhost:3000`
