# Dokumentasi Teknis PDF Manager

## Teknologi yang Digunakan
- Node.js
- Express.js
- Multer (upload file)
- HTML, CSS, JavaScript

## Struktur Folder
- `server.js` → backend server
- `public/` → tampilan web
- `uploads/` → penyimpanan PDF

## API Endpoints
- GET /api/files → ambil semua file
- POST /api/upload → upload file
- DELETE /api/files/:filename → hapus file
- PUT /api/files/:filename → rename file
